# UDS Virtual Machine Operator (`uds-vm-operator`) — Project Handoff & Roadmap

## 1. Objective & Background
This repository implements an air-gap ready **UDS Virtual Machine Operator** (`uds.dev/v1alpha1`, Kind: `UDSVirtualMachine`) designed around the engineering challenges of the [Defense Unicorns Senior Software Engineer - Virtual Machines (RD222)](https://job-boards.greenhouse.io/defenseunicorns/jobs/5272498007) role.

We are deliberately executing a **two-stage operator engineering workflow**:
1. **Phase 1 — Python `kopf` Rapid Prototype (`prototype-kopf/`):**
   - Validate the `UDSVirtualMachine` CustomResourceDefinition (CRD) schema, `+6%` CDI filesystem overhead math, NIST 800-53 compliance controls (`SC-7` Zero-Trust `NetworkPolicy`, `AC-3` hardened Cloud-Init `Secret`, `SI-7` CDI `DataVolume` upload checksum validation), and KubeVirt `VirtualMachine` provisioning.
   - Structured using **pure resource builder functions** and a **single level-triggered `reconcile()` loop** so it maps 1:1 to Go's `controller-runtime`.
2. **Phase 2 — Production Go Conversion (`pkg/` & `cmd/`):**
   - Port the proven Python reconciliation loop and unit tests 1:1 into Go (`controller-runtime` / `client-go`).
   - Run the Go operator binary against the live K3s/KubeVirt cluster to demonstrate seamless controller takeover (`reconciledBy: "kopf-python"` $\rightarrow$ `reconciledBy: "controller-go"`) with zero VM downtime.
